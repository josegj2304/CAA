# SAAC-MX

App gratuita de comunicación aumentativa y alternativa (SAAC) en español de México, para personas que no pueden pagar software de US$300. Funciona sin internet en Android de gama baja.

Estado: kit de arranque (sin código todavía). Empieza por `LEEME_JOSE.md` si eres humano y por `CLAUDE.md` si eres un modelo.
